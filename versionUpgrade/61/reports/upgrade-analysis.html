Recommendations

Recommendation

Migrate from Entity Framework 6.2.0 to Entity Framework Core 8.0.0 as the first critical step. This is a foundational change that affects the entire application. Create a new DbContext inheriting from Microsoft.EntityFrameworkCore.DbContext, convert all entity configurations to IEntityTypeConfiguration, and update all LINQ queries for EF Core compatibility. Implement EF Core migrations for database initialization.

Recommendation

Replace log4net with Microsoft.Extensions.Logging and Serilog.AspNetCore 8.0.0. Update all classes to use ILogger injected via constructor. Convert log4Net.xml configuration to appsettings.json or Program.cs configuration. Update all logging statements to use structured logging patterns.

Recommendation

Convert all 7 ASPX pages to Razor Pages with PageModels. Convert 2 master pages to _Layout.cshtml. Convert user control to partial view. Replace all server controls with HTML and Tag Helpers. Convert Page_Load to OnGet/OnGetAsync and button click events to OnPost/OnPostAsync. This is the most visible change and affects the entire user interface.

Recommendation

Replace Autofac.Integration.Web with built-in ASP.NET Core dependency injection or Autofac.Extensions.DependencyInjection. Move service registration from Global.asax to Program.cs using builder.Services. Convert property injection in pages to constructor injection in PageModels. Remove IContainerProviderAccessor pattern.

Recommendation

Convert Web.config to appsettings.json and appsettings.Development.json. Move connection strings, app settings, and other configuration. Replace ConfigurationManager usage with IConfiguration injection. Set up configuration in Program.cs. Consider using Options pattern for strongly-typed configuration.

Recommendation

Replace Global.asax with Program.cs for application startup. Convert Application_Start logic to WebApplicationBuilder configuration. Convert Application_BeginRequest to middleware. Move session initialization logic to session configuration or distributed cache setup. Remove HttpApplication dependency entirely.

Recommendation

Configure ASP.NET Core session with distributed cache (Redis or SQL Server) for production scenarios. Update all Session access code to use IHttpContextAccessor. Consider stateless alternatives where possible using TempData or client-side storage. Remove HttpContext.Current usage.

Recommendation

Remove RouteConfig and Web Forms routing. Use Razor Pages convention-based routing. For custom routes, configure using @page directive with route templates or Program.cs configuration. Replace GetRouteUrl with Url.Page() and Tag Helpers (asp-page, asp-route-*).

Recommendation

Convert all service methods to async/await pattern. Use ToListAsync(), SaveChangesAsync(), FirstOrDefaultAsync() instead of synchronous EF methods. Update all page handlers to be async (OnGetAsync, OnPostAsync). Add CancellationToken parameters to service methods for proper cancellation support.

Recommendation

Follow clean architecture with separate projects: Domain (entities, interfaces), Application (services, DTOs, mappings), Infrastructure (DbContext, repositories, EF configurations), Web (Razor Pages, ViewModels). Convert to SDK-style project files. Implement proper separation of concerns following upgrade rules.

Recommendation

Replace Web Forms validation controls with Data Annotations on ViewModels and use asp-validation-for Tag Helpers. Implement FluentValidation for complex validation scenarios. Use [ValidateAntiForgeryToken] for form submissions. Enable client-side validation with jQuery validation or native HTML5 validation.

Recommendation

Replace System.Web.Optimization with WebOptimizer NuGet package or use built-in ASP.NET Core bundling. Configure in Program.cs or use bundleconfig.json. Update views to reference bundled assets using Tag Helpers with asp-append-version for cache busting.

Recommendation

Create unit test project for services using xUnit and Moq. Create integration test project for PageModels and repositories. Implement repository pattern to improve testability. Use in-memory database for repository tests. Aim for 80%+ code coverage on business logic.
